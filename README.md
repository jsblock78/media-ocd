# media-ocd (Multimedia OCD)

Hi, I'm Jeff. I have media. I want to organize things. I want to find things. I don't want lost memories.

This project attempts to solve many time consuming tasks and make my media easier to interact with.

## About Me

Hi I am Jeff. I am a gen x'er who enjoys his PC. I've been playing with media since I was a teenager. Even earlier if you count DJ'ing (radio show host, not musician) on my Boombox.

I figured that I would share this projects journey.

## My Media

Right now it is mostly unorganized. Over the years I have had many ways of doing it, but have never gotten everything under one bucket.

I have the following media:
- Photographs that I have taken
- Videos that I have taken
- Television shows
- Movies
- Music albums

## Getting things sorted

I really want to have a nice automated structure for organizing my media.

## Finding things

I'd like to have things so organized that I do not need to search. That said, I want to be able to search. There are instances where good organization cannot overcome a bad memory. If I forget a place or a date, I would still like to be able to find something.

## Redundancy and backup

I want to make sure that I do not lose anything.
